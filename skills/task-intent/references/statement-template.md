# 意图复述模板（≤8 行）

```markdown
- 你要的是：<一句话>
- 为什么要：<一句话>
- 做完的样子：<可检查，1–2 条>
- 不做：<…；没有写「无」>
- 我的假设：<最多 3 条，每条标（把握高/低）>
- 要你拍板的：<最多 1 个问题 + 推荐答案；没有写「无」>
```

## 写法

- 6 个字段都在，顺序不变；全文不超过 8 行。
- 用用户的词，不换成内部术语；一句话一件事。
- 「做完的样子」要能检查（看得到、跑得出、数得清），不写「高质量」「更好」。
- 把握低的假设，若会改变做法或范围，升级成「要你拍板的」；否则留作假设。
