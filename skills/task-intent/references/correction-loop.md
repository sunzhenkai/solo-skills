# 纠偏循环（human 模式）

## 每轮

1. 给出复述，结尾只问一句：「对吗？不对请直接说哪里不对。」
2. 用户说「对 / OK / 可以」→ 确认，结束。
3. 用户指出问题 → 只改被指出的行，再次给出；只展示变化的行并标「已改」。
4. 被纠正过的同一处不得再错；用户纠正与原话冲突时，以最新纠正为准并记入纠偏记录。

## 退出条件（满足任一即退出）

- 用户明确确认 → `status: confirmed`。
- 连续 2 轮没有新纠正，且假设全为「把握高」→ 询问一次后按确认处理。
- 第 3 轮仍有分歧 → 把剩余分歧收成一道二选一（附推荐），用户选完即确认。
- 硬上限 5 轮：仍未收敛则停下，请用户换个说法描述目标，不再猜。

## 禁止

- 一次抛出多个问题清单；没有推荐答案的提问。
- 纠偏时整段重写导致已确认内容漂移。
- 以「用户没回话」当作确认。
