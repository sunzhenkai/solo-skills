# 摸底（只读、并行）

目的：在复述前用最少的上下文摸清现状，避免问能查到的事。

## 分工（按档位取前 N 个）

| # | 分工 | 看什么 | simple | medium | complex |
|---|------|--------|--------|--------|---------|
| 1 | 现状 | 相关代码 / 配置 / 文档的现状与入口 | ✓ | ✓ | ✓ |
| 2 | 历史 | `tasks/` 下相关任务、ADR、近期提交 | | ✓ | ✓ |
| 3 | 反向 | 用户原话里哪些词可能被误解、有几种读法 | | 按需 | ✓ |
| 4 | 外部 | 外部参照（仅 complex 或涉及选型 / 集成） | | | 按需 |

同一批一次性并行发出；不串行等待。

## 交接契约（每个 subagent 都给齐 5 项）

1. 目标：一句话，要回答什么。
2. 输入：用户原话 + 相关路径。
3. 写入范围：只读；详情只许写 `evidence/intent/<分工>.md`。
4. 输出格式：Digest。
5. 停止条件：答到目标或读满约 15 个文件即停。

## Digest（≤10 行）

```text
结论：<1–3 行>
证据：<路径或链接，≤3 条>
未决：<读不到 / 有分歧的点；无写「无」>
置信度：高 / 中 / 低
```

主会话只读 Digest，不转贴全文、不回灌工具轨迹。
