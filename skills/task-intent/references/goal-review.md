# goal 模式：异源强模型代审

goal（自主）模式不问人，由强模型 reviewer 代替人核对复述。

## 调用

`role-based-reviewer roles=intent mode=review model=<比执行者高一档或不同家族的模型>`，随附：用户原话、复述、摸底 Digest。

- 首选：比执行模型高一档；其次：不同模型家族（避开同源偏差）。
- 可用性由调用方（本 skill）先判断：两者都不可用时**不调用** role-based-reviewer，按 taskrail 确认协议登记显式降级（写明原因）后由主会话按本文评分规则自审，并在复述中把所有假设标「把握低」。

## 评分规则

| 维度 | 问题 |
|------|------|
| 忠实 | 有没有添加用户没说的目标、漏掉用户说过的约束 |
| 可检查 | 「做完的样子」能否被检查 |
| 假设 | 假设是否合理、是否标了把握、会改变做法的是否被升级 |
| 范围 | 「不做」是否清楚，有没有越界 |

reviewer 输出：分数 0–1、通过/不通过、P0/P1/P2 发现（含要改的行）。

## 收敛

- 通过：分数 ≥0.8 且无 P0/P1。
- 不通过：主会话按发现修订，再审；最多 2 轮。
- 2 轮仍不过：剩余发现写进显式降级，`status: assumed`，继续推进；不阻塞。
- 线上、不可逆、对外发送相关的意图：一律停下等人，不由 reviewer 放行。
