# Patterns

已经脱离具体 Host、具体项目、具体任务，对任何使用者都成立的经验规律。

## 准入

一条内容要进这里，三条都得满足：

1. **有两次以上独立证据**，来自不同任务的 Trace。单次教训留在 Trace 里。
2. **已脱敏**：不含主机名、项目名、任务细节、账号信息。
3. **是规律不是特例**：换一台机器、换一个项目仍然成立。

达不到的，留在私有数据目录的 Trace 里。这条边界的理由见 [ADR 0001](../../../../docs/adr/0001-ledger-lives-outside-this-repo.md)。

## 写入方式

这个目录**运行时只读**。安装到各 agent 目录是字节复制，运行时写进去的内容会在下次同步时消失。新增或修改必须回到源仓库，走 `$skill-upgrader` 的 `patches/` 审计。

## 格式

一条规律一个文件：`<YYYYMMDD>-<slug>.md`

```markdown
# <一句话说清这条规律>

- Date: YYYY-MM-DD
- Evidence: <支撑它的 Trace 有几条、大致是什么情况，不写具体项目名>

## 规律

<结论本身，写清它在什么条件下成立>

## 不适用的情况

<边界。没有边界的规律通常是还没想清楚>
```
