# 视觉语言、表达组件与布局

[pretty-view-html](../SKILL.md) 工作流第 5–6 步按本页选色、选组件与布局；配色方法见 [frontend-design](frontend-design/REFERENCE.md)，图解见 [html-diagram](html-diagram/REFERENCE.md)。

## 视觉语言与导航

配色由本次内容的主题、读者与阅读任务决定。生成前按 [frontend-design](frontend-design/REFERENCE.md) 选定一组内聚色值并直接写入结果，不要求运行时读取主题文件。每次按内容选色，而非沿用固定色板或通用默认色。

- 同一多页内容包共用一套视觉语言与色义映射。
- 根聚合页已存在时保留其原有视觉语言并增量更新；新建根聚合页时按索引页自身的阅读任务选色，不必套用某篇内容页的色板。
- 重点、状态与结构用选定色板中的强调色编码，而不是只靠字重或灰阶。

每个页面使用一致的顶部导航栏，至少提供根聚合页入口，并在内容包内提供包首页和当前位置。导航栏采用 `position: sticky`、`top: 0` 和明确层级，背景必须足以遮住滚动内容；窄屏可换行或横向滚动，不能隐藏关键入口。

## 表达组件

按内容职责选用具有表达力的语义化组件；组件服务于扫描、对比和操作，不把普通段落一律卡片化。同一多页包共用一套组件语言与色义映射。生成前根据输入挑选足够的组件类型，让页面有真实的组件层次，而非“标题 + 灰段落”的模板页。

| 职责 | 优先组件 | 用色提示 |
|------|----------|----------|
| 内容表达 | 结论/摘要条、导语、定义列表、关键引用、分段说明 | 结论可用主强调色或高亮色边框；引用可用信息色 |
| 标签 / 徽章 | 状态徽章、类型标签、优先级标记、版本/受众 chip | 状态映射错误/警告/成功语义色；类别用次级色区分 |
| 架构 / 可视化 | 分层架构、流程步骤、关系图、状态/时序图、图例、时间线（按 [html-diagram](html-diagram/REFERENCE.md) 选型） | 层级与连线用主色与信息色区分；图例颜色必须有语义 |
| 对比 / 决策 | 对照表、优劣矩阵、方案并列表、决策记录、取舍说明 | 正向用成功色、负向用错误色、权衡用警告色；决策结论加强调色 |
| 教程 / 操作 | 有序步骤、检查清单、命令/代码块、`kbd`、注意事项 callout | 步骤序号用主强调色；警告/阻断用警告或错误色 callout |
| 数据 / 状态 | 指标条、进度、状态面板、字段表、结果汇总 | 达标用成功色、异常用错误色、待定用警告色；关键数字可用高亮色 |

约束：

- 只表达输入中真实存在的信息；不为“好看”虚构指标、状态或对比项。
- 卡片、徽章和 callout 只用来编码真实职责或语义（装饰性编号、无意义图标行、卡片海洋都算模板化装饰）。
- 图解按 [html-diagram](html-diagram/REFERENCE.md) 选型与绘制；优先语义 HTML/CSS/SVG，复杂图必须配文字说明与图例，并嵌入阅读页而非默认拆成独立文件。
- 颜色不单独承担全部含义：同一状态同时提供文字标签，并保持足够对比度。

## 阅读与布局要求

- 内容优先：用清晰的信息层级、适宜行宽、稳定节奏和充足留白支持连续阅读。
- 桌面端默认采用偏宽的阅读布局：内容容器宜充分利用视口，常见上限可落在约 `1200–1600px`，配合响应式侧边距与 `clamp()` 内边距，而非传统窄文章栏。
- 连续长文段落可略收窄以保持行长可读；表格、代码、图解、对照与多栏区域使用内容容器的完整宽度。
- 按内容类型、主要阅读任务和视口自适应宽度；局部宽内容在自身容器内滚动，不撑破页面。
- 控制字体数量；装饰仅保留能帮助理解、建立辨识度或承载组件语义的元素。重点、状态与结构差异优先用选定色板中的强调色表达。
- 正文、表格、代码、引用、提示和图片都要在桌面与窄屏上易读；宽表格允许横向滚动，不能撑破页面。
- 使用语义化 HTML，保持标题层级连续，并提供明确的页面标题、语言属性和 viewport。
- 链接和控件具有清晰文本、可见键盘焦点与足够对比度；含义同时由文字承载。
- 动效必须服务阅读，默认克制，并尊重 `prefers-reduced-motion`。纯阅读页不为“高级感”强行动画。
- 优先生成可独立打开的静态页面。除非确有必要，不依赖构建步骤、前端框架或必须联网加载的资源。
