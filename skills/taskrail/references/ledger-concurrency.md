# 台账并发写入（附录）

多会话 / 多 agent 同时写同一台账时用。单会话顺序写不必读。

1. **锚点唯一才动手**：写前重读目标小节；插入锚点（小节标题、表头或被替换整行）在文件中恰好出现 1 次才写，否则重读定位。
2. **INDEX 行整行替换**：替换后核对列数与表头一致、任务列前缀正确、文件行数变化符合意图（追加 +1，更新 0）；不符就用原行改回并停。
3. **删除只按整行精确匹配**，删后行数恰减 1；不按内容过滤批量删。
4. **编号先读最大号**：追加 `D-n` 前读当前最大号，追加后无重复；新内容插到目标小节末尾。
5. **冲突不静默覆盖**：文件自上次读取后被改过就重读；与既有内容矛盾时写一条带日期的「更正」，不改写他人小节；合不了就停下说明。
