# Reference 统一契约

每个路由型 reference 都按下列结构写。路由依赖产物与证据，不依赖固定线性阶段。

```markdown
# <name>
## 目的
## 进入条件
## 跳过条件
## 所需输入
## 执行方法
## 产出
## 完成门
## 退出与重入
```

要求：

- 进入条件写可观察信号，跳过条件写已有证据；不能用“复杂 / 简单”代替。
- 所需输入是文件、判据或事实，不是“必须先走某阶段”。
- 完成门必须可由文件、命令、测试或评审结论检查。
- 重入只修订受影响产物；没有新证据不得重复完整执行。
- reference 只声明自己的动作。路由选择统一在 [router.md](router.md)，状态与目录统一在 [contract.md](contract.md)。
- 支撑策略（UI、外部参照、质量、多 worker）在环节内按需加载，不另占 current_ref。
