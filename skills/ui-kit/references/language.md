# 设计语言 v1

[ui-kit](../SKILL.md) 的设计语言。本页定义所有风格包共用的结构与规则；具体数值在风格包 `theme.css` 里，不在本页。

## 1. 原则

1. **外观只在代码里**：可见的几何、颜色、字体、动效都来自复制进项目的模板代码与主题变量；页面不写样式。
2. **模型只写内容**：页面拼装页面模板与认证组件，传数据、文案和回调；缺能力时补组件，不在页面里画。
3. **中性做主，强调有预算**：中性灰承担约九成画面；强调色只给主操作、开关开启、焦点环、链接和数据图表。
4. **选中用中性**：导航、标签、筛选的选中态用中性灰底，不用强调色。
5. **深度靠表面**：层级先由表面明度区分，阴影只给浮层（菜单、弹层、对话框）。
6. **取值来自刻度**：字号、间距、圆角、阴影、时长都从 token 取；缺就补 token。
7. **状态完备**：每个交互组件都有默认、悬停、按下、聚焦、禁用；每个数据区域都有加载、空、出错。
8. **键盘可达**：所有操作可用键盘完成，焦点可见；命令面板是全局入口。

画面层面的通用规则（层级、分组、行长、对比度）沿用 pretty-ui 的十条铁律与规则号。

## 2. 分层与所有权

| 层 | 内容 | 所有者 | 项目能否改 |
| --- | --- | --- | --- |
| token | 颜色角色、刻度（字体、字号、圆角、阴影、动效） | 风格包 | 只改白名单（tokens.md） |
| 基础组件 | shadcn/Radix 组件，按语言调过外观 | 模板 | 不改，lock 哈希校验 |
| blocks | 通用组合件（表格、页头、状态边界、属性栏等） | 模板 | 不改 |
| 应用骨架 | 外框、侧栏、内容面板、状态栏、命令面板 | 模板 | 不改 |
| 页面模板 | 列表、详情、表单、设置、画廊、空状态等整页组件 | 模板 | 不改 |
| 页面 | `src/pages/*`，用页面模板拼装并填数据 | 项目 | 可改，只引用认证组件 |

确需改模板文件时记入项目 `local_edits` 并写原因，该文件退出保真保证；同类改动出现两次，回馈模板仓。

## 3. 表面与层级

由下到上四层，每层比下一层更亮（亮色）或更亮一级（暗色）：

| 层 | token | 用途 |
| --- | --- | --- |
| 外框 | `app-shell` / `sidebar` | 窗口底色；侧栏与状态栏直接坐在上面，不另加底色 |
| 内容面板 | `background` | 页面主体；四周留外边距、`xl` 圆角、`border` 细描边 |
| 卡片 / 输入 | `card` | 分组卡、输入框、示例卡；`lg` 圆角、细描边、无阴影 |
| 浮层 | `popover` | 菜单、弹层、对话框、命令面板；`floating-shadow` |

分隔优先用表面差和间距；卡内行与行之间用一条 `border` 细线；一处分隔只用一种手段。

## 4. 排版

| 角色 | token | 字重 |
| --- | --- | --- |
| 页面标题 | `text-2xl` | 600，略收紧字距 |
| 分组标题 | `text-lg` | 500 |
| 正文、导航、控件 | `text-sm` | 400；导航与标签 500 |
| 说明、辅助 | `text-xs` 或 `text-sm` 配 `muted-foreground` | 400 |
| 代码、ID | `font-mono` | 400 |

字重只用 400 / 500 / 600。数字列用等宽数字。说明文字靠颜色降级，不靠更小的字号堆叠层级。

## 5. 间距、密度与形状

- 间距基于 4px：4、8、12、16、24、32、48。组内间距小于组间间距，至少差一档。
- 密度 compact：控件高 28px（侧栏行、下拉、胶囊）或 32px（表单输入），列表行 36px，设置行按内容自适应、上下内边距一致。
- 圆角三档：控件 `md`，卡片 `lg`，内容面板与大输入卡 `xl`；同层元素圆角一致。
- 边框 1px；2px 只给焦点环。

## 6. 色彩用量

- 中性色无彩或极低彩度，冷暖与品牌一致。
- 强调色（`primary` / `brand`）：主按钮、开关开启、发送、焦点环（`ring`）、链接；一屏的强调色面积约一成以内。
- 语义色（`destructive` / `warning` / `success` / `info`）只表达状态，并同时配文字或图标；浅底用同色相低透明度。
- 图标默认跟随文字色降一级；分类标记可用单个彩色小图标。

## 7. 图标与动效

- 图标：Lucide，16px；描边粗细由风格包定，全局一致。
- 动效：悬停、按下用 `duration-fast` 只变底色；菜单、弹层、对话框用 `duration-base` 淡入加轻微缩放；缓动 `ease-out`；不用弹簧、回弹和位移。遵守 `prefers-reduced-motion`。Motion 库只用于进出场与布局动画，其余用 CSS 过渡。

## 8. 数据与状态

- 服务端数据用 TanStack Query；接口边界用 Zod 解析，解析失败按出错态展示。
- 每个数据区域由状态边界组件统一渲染加载（骨架）、空（说明 + 一个主操作）、出错（原因 + 重试）。
- 集合必须声明分页语义（完整集合或“还有更多”），页脚计数与之一致。

## 9. 页面模式

每个模式对应模板仓里的一个页面模板：

| 模式 | 结构 |
| --- | --- |
| shell | 外框 + 侧栏（分组、可折叠）+ 内容面板 + 状态栏 + 命令面板 |
| collection | 页头（标题、视图切换、筛选、主操作）+ 面板内满宽列表行 |
| detail | 主列 + 右侧属性栏；或页头 + 标签页 |
| form | 单列，标签在上，主操作在底部右侧 |
| settings | 面板内居中窄栏；分组标题 + 卡片，行内左标签与说明、右控件 |
| gallery | 居中网格卡片：图标、标题、说明、元信息 |
| empty | 居中插图位或图标 + 一句说明 + 一个主操作 |
| conversation | 消息流 + 底部输入卡 |

## 10. 文案语气

动词开头、说清结果（“创建项目”而非“确定”）；错误信息写原因和下一步；不用感叹号和客套话。

## 11. 保真的定义

- **除自定义外视觉一致**：同一 story（组件状态矩阵或页面模板，固定 fixture 数据）用项目主题渲染，与模板仓用同一主题渲染的基线逐像素一致。
- **跨模型稳定**：同一需求与 fixture，交给不同模型只按本 skill 搭建，截图在内容区以外的像素差异低于阈值。
- 页面内容（数据、文案）不在保真范围内；`local_edits` 与 `custom/` 区登记的偏离不在保真范围内。
