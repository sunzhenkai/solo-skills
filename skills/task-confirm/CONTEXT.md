# Task Confirm

human / goal 确认与审阅协议：闸口放行、派审、退出点。不编排档位、不执行步骤（编排归 taskrail）。

## Language

**完成判据**:
一条可检查的话，用来判断任务是否做完。
_Avoid_: 目标, objective, 交付标准

**交付标准**:
完成判据之外、本任务应有的交付面要求，每条可检查。
_Avoid_: 完成判据, 详细设计, 质量目标

**审阅者**:
每次审阅给出完成程度与 P0/P1/P2：role-based-reviewer、agent-roster、subagent 三选一。
_Avoid_: 审计者

**完成程度**:
高 / 中 / 低；评审通过只看是否为高。
_Avoid_: 复杂度, 方案置信度（旧名）

**退出点**:
必须停下来、把决定交回人的条件。
_Avoid_: 暂停, 阻塞点

**授权**:
用户明确接受某条退出点已点名的动作。单独「继续」不算。
_Avoid_: 点头, 路由确认

**复杂度档位**:
简单 / 中等 / 复杂；由 taskrail wizard 判定，本协议不重判。
_Avoid_: 完成程度
