# 状态机：事件枚举与迁移网格

每轮开头把本条输入对照「事件」节归到一类，再在网格里找 `(当前状态, 事件)` 格；有格按格走，已停行没有的事件按空格调「无进展轮」。**网格与正文或「无进展轮」有出入时，以正文与无进展轮为准。**

**blocked**：「已停」的交接形态，不是第五状态。达成后给出交接摘要（已完成、未完成、证据、下一步），goal 留在已停，等用户处理。本表只在 blocked 格出现时引用它。

子状态（完善中、审阅循环、写完之后）不是第五状态：各归属四状态之一，行内的迁移只在备注里点一句；详细规则见正文对应小节。

## 事件（封闭枚举，11 种）

- **用户授权**：用户点名接受退出点已列的动作；「仍按此方案执行」视为对「审阅收敛后续走」的授权。
- **用户继续**：用户只回「继续」或同义短句，没点名授权项。
- **用户改向**：用户改任务、改判据、升档或换路由的明确消息。
- **goal 自动续跑**：续跑提示来自 goal 系统而非用户回复。
- **审阅收敛**：完成程度为高且无未消失 P0/P1（P2 已写入坑）。
- **审阅未收敛**：本轮有 P0 或 P1，或核过仍在 / 第二次核对仍有 / 写不出改法。
- **退出点命中**：撞上退出点任一标签（理解不够、审阅不通过、审阅派不出、审阅没有结论、评审者未定、降级未确认、阻塞解不开、未点名的危险操作、线上动作、同一验证连败两次、泄密、执行中升档）。
- **判据成立**：完成判据成立且交付标准全过（复杂档还要求质量画像齐全、pending 降级为 0）。
- **步骤推进**：执行中验证掉一个步骤，或已交接勾掉一个 checkbox。
- **外部新事实到达**：非用户消息、非自动续跑，但带来会改步骤或判据的新事实（环境变化、查证结果）。
- **用户补充信息**：用户答复了执行者的事实性问题，不含授权/改向语义。

## 无进展轮（兜底）

状态与退出点和上一轮**完全相同**、且本轮没有带来新的外部输入（用户消息、审阅结论、环境新事实均不算）时，禁止原样重复上一轮回复：

- 已停且该输入形态在网格里有格 → 按格走；
- 已停且该输入形态无格 → 做「授权」节列名的只读工作；无可做的只读工作时，按 goal 自动续跑第 3 次处理：标记 blocked，给交接摘要，不再原样重申。
- 执行中 / 已交接出现无进展轮 → 视为协议异常，状态改已停，路由写「无进展轮兜底触发」，等用户处置。

## 与既有规则的关系

- 「授权」节第 3 段（goal 自动续跑 1~2 次只读查证、第 3 次 blocked）在此登记为「已停 × goal 自动续跑」一格，语义不变。
- 「授权」节第 2 段（授权封闭集合）与第 4 段（无进展轮）共同构成已停行的规则；本表不新增授权项。
- 退出点、审阅、写完之后各小节的散文规则是这些格子的**定义来源**；本表只做索引与穷举，不替代正文。
